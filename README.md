# Доступний веб

Односторінковий практичний посібник з вебдоступності українською мовою: принципи POUR, ключові критерії WCAG 2.2, часті запитання й форма запиту на консультацію.

Навчальний проєкт з дисципліни «Веб-програмування» (лабораторна робота № 17), МЕГУ ім. Степана Дем’янчука, група КІІ 61б.

**Опубліковано:** https://vadim-sketch0.github.io/a11y-guide/

## Стек

- [Vite](https://vite.dev/) – збирання й сервер розробки
- [Tailwind CSS 4](https://tailwindcss.com/) через `@tailwindcss/vite` – уся стилізація утилітами, дизайн-токени в `@theme`
- Prettier + `prettier-plugin-tailwindcss` – форматування й сортування класів
- Шрифти Inter (змінний) і Merriweather 700 – власні WOFF2-підмножини (кирилиця, латиниця) з `font-display: swap`

JavaScript-фреймворків немає: лише ~2 КБ скрипту для перемикача теми, закриття меню й підсумку помилок форми.

## Можливості

- 8 секцій: шапка з липким позиціонуванням і мобільним меню на `<details>`, головний екран, принципи, детальний розділ, таблиця критеріїв, FAQ, форма, підвал
- Mobile First, 4 стани макета (від 320 px до широких екранів), контейнерні запити для компонента «порада»
- Світла й темна теми на семантичних токенах; пріоритет: вибір користувача → системна перевага → світла
- Доступність рівня WCAG 2.2 AA: семантичні орієнтири, посилання пропуску, видимий фокус, доступна форма
- `motion-reduce:` для всіх анімацій, стилі друку `print:`
- Адаптивні зображення AVIF / WebP / JPEG із `srcset` і `sizes`

## Структура

```
a11y-guide/
├── index.html          розмітка всіх секцій
├── vite.config.js      base для GitHub Pages, плагін Tailwind
├── package.json
├── .prettierrc
├── design/
│   └── make-images.cjs генерація ілюстрацій (SVG → AVIF/WebP/JPEG)
├── public/
│   ├── favicon.svg
│   ├── fonts/          WOFF2-підмножини
│   └── img/            hero-*, contrast-* у 3–4 ширинах і 3 форматах
└── src/
    ├── style.css       @import "tailwindcss", @theme (примітиви й семантичні токени), темна тема, @font-face
    └── main.js         перемикач теми, мобільне меню, форма
```

## Складання

```bash
npm install
npm run dev       # http://localhost:5173/a11y-guide/
npm run build     # виробнича збірка в dist/
npm run preview   # перегляд збірки
```

Публікація: вміст `dist/` розміщено в гілці `gh-pages`, яку GitHub Pages віддає як сайт.
